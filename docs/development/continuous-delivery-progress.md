# 自动续推交接

本任务已按用户要求启用每小时自动续推。保持现有 Vue 3 / Spring Boot / MyBatis / MySQL 模块边界，只读取本轮相关需求与文件，避免每轮重新扫描整个仓库。每次完成有验收证据的业务闭环后提交并推送，不等待逐次“继续”。

## 已完成的最近闭环

- B7 外部访问核查目录、发现、标识登记/纠错、分派与催办：本地退出批准同事务生成门户账号、门禁、接口凭证三渠道任务；管理端可按供应商范围记录发现与逐外部标识证据，错误登记可留痕作废并重新登记；责任人实时核查待办可定位申请，人工站内催办按 24 小时限频并在失败时回滚；逾期自动站内催办有独立租户开关、默认关闭，投递失败次数/原因/恢复在核查目录可见。人工标识登记/作废并非真实门户身份绑定或外部回收成功。见 [核查目录验收](exit-access-recovery-inventory-review.md)。统一跨业务任务中心、真实身份绑定、连接器、幂等回调和重试仍缺。

- B2 搜索新增绩效评价、现场出入及结果定位：各对象权限/范围独立校验，双租户 MySQL 验证；安全、质量台账接收编号关键词，绩效与现场出入结果通过授权详情打开。见 [搜索验收](business-global-search-review.md)。其余业务对象和真实后端浏览器 E2E 仍缺。

- B2 搜索新增安全隐患与质量不符合项：沿用各自台账权限和范围，支持关键词/状态/时间、保存方案与管理端跳转；详见 [搜索验收](business-global-search-review.md)。

- B2 业务全局搜索基础：供应商、合同、项目、人员和车辆设备共用关键词/类型/状态/时间筛选，入口及对象级权限、租户/数据范围过滤、管理端页面与台账跳转；人员敏感字段不检索，个人搜索方案页面补默认回填、另存、应用、更新和删除，参见 [搜索验收](business-global-search-review.md)。后续新增对象见上方增量记录；真实后端浏览器 E2E 仍缺。
- B7 资源受控动作细分：人员登记/启用与设备登记/使用分别固定路由，限制解释、门禁命中及契约同步；参见 [资源动作验收](resource-action-routing-review.md)。局部范围与未落地渠道仍缺。
- B7 退出本地记录封存：批准同事务记录申请、结果、全部处置项/实体/事件摘要与数量，读取重算检验、租户范围及审计；参见 [封存验收](exit-local-archive-review.md)。不复制依据文件或宣称外部访问回收、完整文件归档。
- B7 企业级业务门禁命中台账：实际业务检查的 WARN/DENY 独立事务留痕、供应商范围分页查询，解释查询不混入；参见 [命中验收](restriction-business-gate-hit-review.md)。局部范围与旧 generic 入口仍缺。

- 安全隐患与现场出入列方案：B2-07 扩展至九表，安全两表权限分离、必显标识和现场、固定整改/签退操作；参见 [安全台账验收](safety-table-views-review.md)。其余台账及真实后端浏览器 E2E 未完成。

## 开发与验收约束

- 检查工作区，保留所有用户改动。独立且边界明确后再并行，不做重叠文件写入或同工作区并行 Maven 构建。
- 模块单测优先；数据库/跨模块变更使用隔离 MySQL 集成验收：`./mvnw -q -pl backend/ism-bootstrap -am -Pintegration-test verify`。
- 修改接口后生成客户端并构建相关前端；提交生成文件后运行 `corepack pnpm check:api`。
- V25 原始 SQL 已按用户明确修复请求恢复，新增 V41 回填快照列，见 [校验恢复](v25-checksum-recovery.md)。旧记录不改 checksum；其他数据库若使用误修改 V25，仍须核对版本/结构并备份，不能自动 repair、清库或关闭校验。
- 只清理自己创建的临时资源。真实外部依赖、必要权限或高风险数据变更再请求用户介入。
