# 供应商主数据

供应商档案是准入、资质、合同项目、人员设备、质量绩效和限制退出的统一主数据，不允许各业务模块重复维护供应商名称。

## 业务规则

- 供应商编码在租户内唯一，创建后不可修改；统一社会信用代码非空时也必须租户内唯一。
- 档案必须归属一个有效组织，并受 `supplier:master` 数据权限控制。
- 类型支持生产商、贸易商、服务商、承包商和其他；风险分为低、中、高。
- 联系人最多 20 个，最多一个主要联系人，每个联系人至少提供一种联系方式。
- 状态机为 `DRAFT -> ACTIVE -> SUSPENDED -> ACTIVE`；草稿、有效或停用状态均可退出，`EXITED` 为终态。
- 停用和退出必须填写原因；原因进入审计事件，不污染档案备注。
- 更新和状态变更使用 `version` 乐观锁，并发冲突返回 409。

## 权限点

- `supplier:master:view`
- `supplier:master:create`
- `supplier:master:update`
- `supplier:master:status`

前端隐藏按钮只用于改善体验，后端权限和数据范围始终是最终授权边界。

## 管理端档案维护

- 台账详情展示完整主档和联系人；全局搜索按供应商 ID 直达详情，不依赖当前列表分页。
- 台账可同时按关键词、状态、供应商类型和风险等级筛选，计数与分页使用相同条件；类型/风险来自固定主档枚举，不等于可配置采购品类或合作关系范围。筛选仍受租户及组织/创建人数据范围约束。
- 租户采购品类独立于固定供应商类型，维护编码、名称和启停；编码租户内唯一且不可修改。一个供应商可关联最多 20 个品类，关联更新沿用供应商主档版本并写审计。停用品类不再允许新增关联，原有历史关联仍可查询和保留；已退出供应商不得修改关联。台账可按品类与类型、风险、状态组合筛选。
- 品类目录维护要求独立的 supplier:category:manage 权限（迁移授予既有租户管理员，新租户管理员开通时获取）；关联修改沿用 supplier:master:update，读取复用 supplier:master:view。关联对象仍按 supplier:master 数据范围授权。该分类不自动决定准入、限制或退出范围。
- 非退出状态可编辑基础资料及最多 20 个联系人，主要联系人最多一个；保存携带详情版本并由后端复核归属组织、数据范围、唯一性和联系人规则。已退出档案只读。
- 详情可停用有效供应商，必须填写原因；草稿或停用供应商可申请启用，最终由后端复核限制和退出处置。页面操作成功后刷新台账。直接退出仍走独立退出申请。

## 可独立验收

1. 两个租户可以使用相同供应商编码，租户之间互不可见。
2. 同租户重复编码或重复统一社会信用代码返回 409。
3. 组织范围用户不能查询、编辑或变更范围外供应商，按不存在处理，避免泄露 ID。
4. 联系人无联系方式、存在多个主要联系人时返回参数错误。
5. 非法状态跳转、无原因停用或退出被拒绝；退出后不能恢复。
6. 使用旧 `version` 更新或变更状态返回 409。
7. 搜索直达非当前分页的档案详情；编辑多联系人提交唯一主联系人与版本，旧版本冲突时联系人不被替换、审计不新增；停用原因进入状态审计。
8. 类型与风险可以组合筛选；不同类型、风险、组织范围或租户的供应商不得进入结果或总数，重置后恢复全部可见记录。
9. 同租户重复品类编码被拒；旧版本更新返回冲突；多个品类可关联同一供应商，重复 ID、跨租户 ID、停用后新增关联被拒；旧版本关联不能覆盖新关联。停用品类保留既有历史关系，已退出档案不能再编辑。
