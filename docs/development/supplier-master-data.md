# 供应商主数据

供应商档案是准入、资质、合同项目、人员设备、质量绩效和限制退出的统一主数据，不允许各业务模块重复维护供应商名称。

## 业务规则

- 供应商编码在租户内唯一，创建后不可修改；统一社会信用代码非空时也必须租户内唯一。
- 档案必须归属一个有效组织，并受 `supplier:master` 数据权限控制。
- 类型支持生产商、贸易商、服务商、承包商和其他；风险分为低、中、高。
- 联系人最多 20 个，最多一个主要联系人，每个联系人至少提供一种联系方式。
- 状态机为 `DRAFT -> ACTIVE -> SUSPENDED -> ACTIVE`；草稿、有效或停用状态均可退出，`EXITED` 为终态。
- 停用和退出必须填写原因；原因进入审计事件，不污染档案备注。
- 更新和状态变更使用 `version` 乐观锁，并发冲突返回 409。

## 权限点

- `supplier:master:view`
- `supplier:master:create`
- `supplier:master:update`
- `supplier:master:status`

前端隐藏按钮只用于改善体验，后端权限和数据范围始终是最终授权边界。

## 可独立验收

1. 两个租户可以使用相同供应商编码，租户之间互不可见。
2. 同租户重复编码或重复统一社会信用代码返回 409。
3. 组织范围用户不能查询、编辑或变更范围外供应商，按不存在处理，避免泄露 ID。
4. 联系人无联系方式、存在多个主要联系人时返回参数错误。
5. 非法状态跳转、无原因停用或退出被拒绝；退出后不能恢复。
6. 使用旧 `version` 更新或变更状态返回 409。
