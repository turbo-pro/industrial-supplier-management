# B1 套餐操作与字段权限约束

## 已实现规则

V64 为 `sys_permission` 增加可空的 `module_code`，逐项配置现有权限归属。未配置归属的权限默认不进入可授权目录、不允许保存，已有角色即使保留该权限记录也不能使其生效。新增权限必须在新增迁移中明确填写归属；不修改历史迁移。

| 模块 | 当前权限范围 |
|---|---|
| SYSTEM | 组织、账号、角色、导航、字典和租户配置 |
| COMMON | 文件、任务、打印、搜索和表格方案 |
| MESSAGE / WORKFLOW | 消息与工作流公共能力 |
| SUPPLIER | 供应商主档、采购品类 |
| QUALIFICATION | 准入申请、资质证照 |
| PROJECT | 合同与项目 |
| RESOURCE | 人员、车辆设备及人员证件字段权限 |
| SAFETY / QUALITY / PERFORMANCE | 安全、质量与绩效 |
| RESTRICTION | 限制、申诉、解除、退出、退出财务核验 |

目录的权限代码和可读选项、角色授权写入、每次请求的操作/字段权限加载都使用当前租户启用模块集合。公共模块固定保留；业务模块要求当前分配的套餐版本已发布、模块启用且模块目录有效。未开通权限的授权保存返回 422，原版本、权限、菜单和数据范围整笔回滚。

套餐降级保留已存角色权限和菜单供追溯、再次开通；已有 token 的下一次请求按当前套餐重新过滤。内置租户管理员同样受套餐约束。角色授权详情及用户角色影响预览继续展示已存配置，不代表当前最终生效权限。

## 模块边界与导航

IAM 通过公开接口 `TenantModuleEntitlements` 获取业务模块集合，平台的 `PackageModuleEntitlements` 实现负责读取套餐表。IAM 的目录、角色写入及导航 SQL 只操作 IAM/系统目录表，移除 V63 实现中的跨模块套餐表读取。后续拆分控制面可替换该接口实现。

V64 同步调整准入与限制退出菜单归属；供应商导航父分组为公共容器，子菜单仍各自受套餐与角色约束。空 Layout 分组不显示，独立开通准入资质模块可以展示其子入口。

## 验收范围

`B0InfrastructureIT` 的开通场景覆盖：

- 仅供应商套餐时，目录没有人员操作/证件字段权限；复用管理员 token 读取人员台账为 403。
- 开通 RESOURCE 后，同一 token 人员接口为 200；证件字段权限进入有效快照，可保存自定义角色。
- 降级后同一 token 人员接口恢复 403，字段权限移出有效快照；旧授权仍可读，越权保存 422 且版本不变。
- 第二租户目录独立；未映射的新权限即使人工挂入角色也不会生效，目录与写入均拒绝。
- 现有权限全部具有明确归属；独立 QUALIFICATION 套餐仅显示准入/证照及其公共父分组，未启用 RESOURCE 不生效。

`PerformanceMigrationUpgradeIT` 负责从原始 V25 升级至最新版本，验证 V25 校验和及历史绩效记录保留，不执行 repair、清库或关闭校验。

2026-10-17 验收结果：B0 全组 21/21，升级回放 1/1，Failures/Errors/Skipped 均为 0；隔离新库执行 64 份迁移。V25 校验和保持 `1394665689`，原绩效数据及版本保留，重复 migrate 无新增执行。OpenAPI 客户端重新生成和 TypeScript 检查通过。Review 核对 IAM 的套餐判定已通过公开接口调用平台，未引用平台套餐 Mapper 或其表；未涉及前端其他未提交改动。

## 剩余边界

数据范围资源的可选目录和配置尚未按模块归属过滤；实际业务访问仍必须同时通过动作权限与数据范围。完整模块依赖图、菜单操作依赖说明、套餐未来生效/到期/例外授权、独立部署浏览器验收仍待完成。平台 Console 权限使用独立权限表，未纳入租户套餐。
