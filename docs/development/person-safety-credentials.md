# 人员安全培训与作业凭证

人员入场状态与安全凭证关联。管理员可登记培训或特种作业凭证、审核、驳回和撤销，并随时查询人员当前资格。

## 可验收规则

1. 新增人员时可设置特种作业类型：电工、焊接、高处或其他。未设置代表普通岗位；类型登记后不可直接修改，以免绕过已经审核的凭证。
2. 培训记录包含课程、考试是否通过、可选分数、有效期和同租户有效文件。特种作业凭证必须与人员登记的作业类型相同。
3. 凭证从 `PENDING` 可审核为 `VERIFIED` 或 `REJECTED`；`VERIFIED` 可撤销为 `REVOKED`。驳回和撤销必须写原因。审核时阻止过期凭证和未通过考试的培训记录变为有效。
4. 人员从 `PENDING` 或 `SUSPENDED` 变为 `ACTIVE` 时，后端要求至少一条当前有效、已审核且考试通过的培训记录。设置了特种作业类型的人员还需对应类型的有效凭证。
5. 资格接口按当前日期重新计算；凭证到期或被撤销后立即返回不合格。已是 `ACTIVE` 的人员状态不会自动改为 `SUSPENDED`；现场闸机或签到系统若接入，应在每次准入时调用资格接口，不以人员状态代替实时资格。
6. 所有列表、单条读取和写操作均限制在租户及数据权限范围内；修改使用版本号避免覆盖并发审核。

接口位于 `/api/safety/credentials` 与 `/api/safety/persons/{personId}/eligibility`，前端位于 `/safety/credentials`。文件先通过现有上传模块生成，再填写文件 ID。
