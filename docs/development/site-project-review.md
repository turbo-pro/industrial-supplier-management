## 接口与页面

入口 `/projects/site-ledger`，从首选场站页可进入。上下文仅保存在该页面内存；无全局客户端头、URL参数或浏览器存储。候选分页搜索复用IAM授权契约。明确点击进入后签发，场站切换/到期/撤权/登录变化清空旧项目与详情；请求序号阻止旧响应覆盖新工作区。

| 路径 | 方法 | 原业务权限 |
| --- | --- | --- |
| `/api/site-projects` | GET / POST | project:view / project:manage |
| `/api/site-projects/{id}` | GET / PUT | project:view / project:manage |
| `/api/site-projects/{id}/status` | POST | project:status |
| `/api/site-projects/access` | GET | project:view，返回当前动作能力，不能代替数据范围校验 |

所有路径还必须通过IAM场站令牌实时校验。缺少场站上下文返回400；无效/错登录/跨租户/撤权403；跨场站或超出项目数据范围404；版本冲突409；非法状态/日期/原因按原接口400。原项目接口误带场站头422，不能把它当成已过滤接口。套餐未开通同样拒绝。

新建使用服务器SiteContext中的ID，不接收客户端指定归属；供应商自身组织不改。新建前在供应商模块公开契约内锁定并按supplier:master:view和原数据范围复核可见性；关联有效合同再求交contract:view和contract数据范围。OWNED授权不能用指定他人负责人逃出范围。编辑和状态仍遵循原版本及状态机，场站编辑补PROJECT_UPDATE版本/场站审计；新建、状态、审计在同一事务。场站权限不授予项目/供应商/合同权限。预算等字段沿用既有投影，本增量不宣称补齐全项目字段分权。

页面具备筛选/分页、新建、详情、计划中编辑、开工/复工/暂停/完成/取消及原因确认。供应商通过真实共享主档搜索；负责人和可选合同暂用明确标注的ID输入，后续应接各自受权选择器。保存/状态结果未知时不自动重发，要求按项目编码查询核对；项目编码仍租户内唯一，状态及编辑使用版本。未接新增幂等回执能力，不把网络失败解释为未保存。个人列方案尚未推广到本新页面。
