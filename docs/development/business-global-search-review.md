# 业务全局搜索（供应商、合同、项目、人员、车辆设备、安全隐患、质量不符合项、绩效评价、现场出入）验收

新增现场出入：按人员姓名/编号、现场位置或供应商检索，状态 `OPEN`/`CLOSED` 由签退事实派生，固定租户及 `safety:attendance` 组织/项目/创建人范围；不匹配证件号或手机号。结果以记录 ID 打开受 `safety:attendance:view` 与数据范围校验的详情抽屉，不依赖列表分页。隔离 MySQL 覆盖双租户、项目范围、越权详情拒绝；不新增迁移。真实后端浏览器 E2E 尚未验收。

新增绩效评价：检索评价快照中的供应商名称/编码，按 `performance:evaluation:view` 和 `performance:evaluation` 范围限制结果，支持全租户、组织、创建人/本人；状态和更新时间筛选沿用通用请求。搜索结果携带评价 ID，管理端打开时从有权限的详情 API 读取并展示该评价抽屉，不依赖其是否位于当前台账页。安全隐患与质量不符合项导航改为传入编号，目标页读取关键词并加载，避免只打开未过滤台账。`SearchServiceTest` 和隔离 MySQL `B0InfrastructureIT` 覆盖权限、空组织、双租户和组织范围；无数据库迁移。现场出入等其他业务对象仍未接入搜索。

新增安全隐患与质量不符合项：分别复核 `safety:issue:view`、`quality:ncr:view` 和 `safety:issue`、`quality:ncr` 数据范围。安全隐患允许全租户/组织/项目集合/创建人；质量不符合项另允许责任人范围。只匹配编号、标题、供应商名称，不搜索描述或证据内容；结果只显示标题、编号、供应商、状态和更新时间并跳转台账。以下旧段落仅描述先前五类对象的验收范围。

新增验收覆盖 `SearchServiceTest` 的独立权限、空集合阻断，以及隔离 MySQL `B0InfrastructureIT` 的双租户、组织、项目、责任人范围和路由。无数据库迁移；真实后端浏览器 E2E 与大数据量 `%关键词%` 查询性能仍待验收。

管理后台顶部“业务搜索”及既有“高级搜索”菜单均进入搜索页面，支持关键词、对象类型、精确状态、更新时间范围和分页。查询结果可打开对应台账并带入关键词。当前业务目录接入供应商档案、合同、项目、供应商人员和车辆设备。

个人搜索方案页面已接入原有 API：按当前租户与本人读取，默认方案仅预填条件、不自动发起宽泛查询；支持另存、应用、版本化更新条件、重命名、设为默认和删除。默认方案唯一由数据库约束保护，旧版本和其他用户的修改/删除会返回冲突；无方案管理权限时不影响直接搜索。旧方案若包含当前页面不支持的对象或多状态条件，明确提示而不静默裁剪或覆盖。

搜索 POST `/api/search` 沿用 `search:global:use` 入口权限，并对每类结果分别复核 `supplier:master:view`、`contract:view`、`project:view`、`resource:person:view`、`resource:asset:view` 及对应数据范围。SQL 固定租户条件：供应商支持全租户/组织/创建人；合同支持全租户/组织/负责人/创建人；项目支持全租户/组织/项目集合/负责人/创建人；人员和车辆设备支持全租户/组织/项目集合/创建人，与各自台账保持一致。无权限或空集合直接跳过，不执行无范围 SQL；客户端传入的类型不能扩大访问权。人员搜索不匹配证件号、手机号，也不返回这些字段；车辆设备可按车牌检索，但结果只显示资产名称、编号和供应商。所有结果仅返回列表已有的名称、编号、状态与更新时间。

验收：`SearchServiceTest` 覆盖类型权限、范围选择及空范围；隔离 MySQL `B0InfrastructureIT` 覆盖双租户、组织、项目集合、人员/资产范围、人员敏感字段不检索、无对象权限、个人方案默认切换、旧版本冲突及跨用户拒绝。`./mvnw -q -pl backend/ism-bootstrap -am -Pintegration-test verify` 与管理端构建通过。Playwright CLI 使用模拟授权接口检查既有菜单路径、默认方案回填、提交搜索与结果展示；这是页面交互检查，不宣称真实后端浏览器 E2E。未新增数据库表或迁移；当前 `%关键词%` 模糊匹配在大数据量下的性能和真实后端浏览器 E2E 尚未验收。搜索结果只作导航，不是详情授权凭证，目标台账继续自行判权。
