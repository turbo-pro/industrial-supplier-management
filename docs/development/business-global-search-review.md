# 业务全局搜索（供应商、合同、项目）验收

管理后台顶部“业务搜索”及既有“高级搜索”菜单均进入搜索页面，支持关键词、对象类型、精确状态、更新时间范围和分页。查询结果可打开对应台账并带入关键词。当前业务目录只接入供应商档案、合同、项目。

个人搜索方案页面已接入原有 API：按当前租户与本人读取，默认方案仅预填条件、不自动发起宽泛查询；支持另存、应用、版本化更新条件、重命名、设为默认和删除。默认方案唯一由数据库约束保护，旧版本和其他用户的修改/删除会返回冲突；无方案管理权限时不影响直接搜索。旧方案若包含当前页面不支持的对象或多状态条件，明确提示而不静默裁剪或覆盖。

搜索 POST `/api/search` 沿用 `search:global:use` 入口权限，并对每类结果分别复核 `supplier:master:view`、`contract:view`、`project:view` 及对应数据范围。SQL 固定租户条件：供应商支持全租户/组织/创建人；合同支持全租户/组织/负责人/创建人；项目支持全租户/组织/项目集合/负责人/创建人。无权限或空集合直接跳过，不执行无范围 SQL；客户端传入的类型不能扩大访问权。仅返回列表已有的名称、编号、状态与更新时间，不检索联系人或敏感证件。

验收：`SearchServiceTest` 覆盖类型权限、范围选择及空范围；隔离 MySQL `B0InfrastructureIT` 覆盖双租户、组织、项目集合、无对象权限、个人方案默认切换、旧版本冲突及跨用户拒绝。`./mvnw -q -pl backend/ism-bootstrap -am -Pintegration-test verify` 与管理端构建通过。Playwright CLI 使用模拟授权接口检查既有菜单路径、默认方案回填、提交搜索与结果展示；这是页面交互检查，不宣称真实后端浏览器 E2E。未新增数据库表或迁移；当前 `%关键词%` 模糊匹配在大数据量下的性能和真实后端浏览器 E2E 尚未验收。搜索结果只作导航，不是详情授权凭证，目标台账继续自行判权。
