# GAP-01 支持访问发布复核

范围：B1-01/06/07/12，依据已确认 PRD 68。这里区分独立切片和批次门禁，不将接口存在或历史回归当成整体验收。

| 验收编号 | 已有证据 | 剩余门禁 |
|---|---|---|
| SUPPORT-AT-001 / 002 | Console 控制面及员工业务接口的 Realm 隔离已有真实 HTTP、双端浏览器证据。 | 对照 PRD 逐个核验可访问的控制面字段及所有直接业务入口；当前部分拒绝为 401，未将其当成 PRD 指定的 403。 |
| SUPPORT-AT-003 | 进入令牌短时、浏览器绑定、原子消费；已有重复、过期、不同浏览器及并发测试。 | 最终发布基线将原定向用例与实际浏览器路径统一重跑。 |
| SUPPORT-AT-004 | Console 路径错租户拒绝并记入平台审计；独立工作台的目标租户从服务端会话确定。 | 对已验明归属的错租户请求补告警证据，拒绝匿名请求时不得假冒操作者。 |
| SUPPORT-AT-005 / 006 | 工作台只显示按 ID 读取；投影在后端裁剪，浏览器和 HTTP 均验证批准字段。 | 将员工写入、搜索、下载、导出及错误输出列入直接 API 负向门禁，验证不泄露或不开放。 |
| SUPPORT-AT-007 | Console 及工作台主动撤销、租户撤回即时拒读，界面清屏，旧访问秘密重放失败。 | 工作台未签发刷新或下载凭证；整包核验这些能力无法绕过会话或被普通 API 误签发。 |
| SUPPORT-AT-008 | 原申请人不能独立自批；未完成租户审批不能签发。 | 当前仅供应商基础字段只读，未实现高风险操作审批与启用，不以只读验收替代。 |
| SUPPORT-AT-009 | 成功读取和可归因拒绝审计包含平台操作者、目标租户、会话、对象及 trace。 | 还需有权限的会话访问日志查询；范围外和匿名拒绝不应被伪造为某个支持操作者的动作。 |
| SUPPORT-AT-010 | 没有把平台身份替换成员工身份。 | 尚无业务时间线展示代操作身份的证据。 |
| SUPPORT-AT-011 | 供应商投影同时过滤目标租户和组织范围，普通工作台请求不能指定其他租户。 | 补真实外租户供应商 ID 对照，并对齐全局主键设计下的同 ID 隔离等价验证。 |
| SUPPORT-AT-012 | 独立工作台与普通租户身份相互拒绝。 | 补集团管理员组织范围到 Console 支持入口的完整负向路径。 |

还未交付的 PRD 页面与接口：Console 会话列表/详情、剩余时间、人工终止、可审计访问日志查询，以及高风险路径；固定提示已有租户、实际操作者、范围和 UTC 截止，但未按 PRD 显示实时剩余时间及橙色提示。现有独立工作台仅提供已验证的供应商投影。

优先次序：先补 Console 会话状态及审计查询，再处理错租户告警及整体验收。已可复验的 B1 前置缺口照原依赖推进；生产域名、证书和外层代理仍需在实际部署环境验证。

2026-11-06 本地 HTTPS 代理验收：`node scripts/verify-reminder-e2e.mjs --support-workspace-proxy` 构建干净提交的 Console 与管理端，以真实 Nginx、两套回环 HTTPS 来源、Chrome、Spring Boot 和隔离 MySQL 通过 1/1。核对固定 opener 策略、独立 HTML 与资源 404、受控交接、API 的 `no-store`、主动退出、租户撤回和最终审计。证据：`output/playwright/support-workspace-proxy-e2e-1793977332954/proxy-assertions.txt` 及同目录数据库验收。配置和回滚见 [代理部署说明](../../deploy/nginx/README.md)。只新增代理模板、验收脚本及证据，无迁移、产品接口或客户端变更。
