# 集团、总部与场站组织模型

每个租户初始化时都创建且仅创建一个 `HEADQUARTERS` 根组织。单场站租户同样保留总部根节点，可直接在其下创建一个 `SITE`；集团型租户可按 `HEADQUARTERS -> SUBSIDIARY -> SITE -> DEPARTMENT` 扩展，分子公司和部门允许继续分层，场站下只能创建部门。

组织使用邻接关系保存直接父级，并使用闭包表保存祖先和后代关系。这样总部汇总、下级数据范围、组织切换和未来跨层统计不依赖递归字符串路径。组织编码在租户内唯一；总部不可停用；存在有效下级时上级不可停用；已停用组织不能作为当前操作组织。

用户可以绑定一个或多个授权组织。切换范围包括直接授权组织及其全部下级组织，不允许依靠前端传入任意组织 ID 越权。当前操作组织保存在 `iam_user_context`，仅代表界面和新增数据的默认归属，不扩大角色数据权限。

组织表、闭包表、用户组织关系和当前上下文均强制携带服务端租户上下文。组织树接口只返回当前租户；Console 平台身份不能调用租户组织接口。

验收要求：单场站和多场站共用模型；非法父子类型被拒绝；组织编码不能重复；总部授权用户可以切换到下级场站；无关组织不可切换；有有效子级的组织不能停用；所有组织 SQL 通过租户隔离拦截器。
