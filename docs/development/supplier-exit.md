# 供应商退出前合同与项目处置

供应商档案列表的“退出检查”展示待处置数量。`GET /api/suppliers/{id}/exit-readiness` 返回检查项；真正退出仍使用原有状态接口，必须填写原因并带版本号。

- 合同 `DRAFT/ACTIVE` 阻止退出，须终止或完成；`EXPIRED` 为结束态。
- 项目 `PLANNED/ACTIVE/SUSPENDED` 阻止退出，须取消或完成。
- 前端预览不是授权依据；后端在退出事务中重新检查，并与新增合同、项目共用供应商行锁。
- 历史记录保留，`EXITED` 不可恢复；不自动终止合同、取消项目，不代替人工处置决策。

各模块实现 `SupplierExitCheck` 公开接口，供应商模块不直接查询外部表。未配置检查提供者时拒绝退出。本轮只覆盖合同与项目；人员离场、现场出入、质量、安全、应付款结清等退出检查尚未完成，不能将本轮视为完整 B7 验收。
