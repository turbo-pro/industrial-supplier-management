# 质量不符合项与纠正预防措施

管理后台入口 `/quality/nonconformances`，接口入口 `/api/quality/nonconformances`。质量事实绑定一个进行中的项目及其供应商，用于后续供应商绩效计算。当前范围是验收发现不符合项后的处理闭环，不包含抽样方案、批次追溯或自动评分。

## 可单独验收的规则

1. 登记必须选择当前租户进行中的项目、有效供应商、当前租户有效责任人和有效证据文件；编号在租户内唯一。
2. 验收日期不能晚于当前日期，整改期限不能早于验收日期；验收和缺陷数量均大于零，缺陷数量不能超过验收数量，最多三位小数。
3. 状态只允许 `OPEN → PENDING_REVIEW → CLOSED`；复验驳回则 `PENDING_REVIEW → OPEN`，可以再次提交措施。根因、纠正、预防措施及措施证据均为必填。
4. 每次创建、提交措施和复验均在同一事务中记录处理事件与审计；处理历程保留以往的说明与附件，不被再次整改覆盖。
5. 所有读取和写入按租户与 `quality:ncr` 数据范围限制；状态更新使用版本号，过期请求返回冲突。列表支持编号、标题、供应商关键词和状态过滤。
6. 关闭的不符合项不再可编辑或复验；未关闭且超过期限时标识逾期。签署/电子签名、来料批次和绩效扣分将在后续独立设计，不把当前数据误当成已完成这些能力。
