# 统一任务中心

导入、导出、批量下载和耗时计算统一提交为异步任务。任务记录包含任务号、类型、请求人、状态、0–100 进度、当前阶段、重试次数、错误摘要和结果文件 ID。执行节点通过 `FOR UPDATE SKIP LOCKED` 和限时租约竞争任务；节点失联后其他节点可接管，旧节点不能再更新或完成任务。

用户只能查看、取消和重试自己的任务。排队任务取消后立即结束，运行任务记录取消请求并由执行器在阶段边界停止；失败或已取消任务最多自动/人工重试三次。执行器可更新 0–99 的进度，成功时统一置为 100，并可关联文件中心生成的结果文件。

验收要求：同一任务只能被一个有效租约执行；租约过期可恢复；旧节点不能完成；进度和阶段可查询；乐观锁防止重复取消/重试；成功任务不可重试；失败摘要不包含敏感请求数据；结果文件继续受文件下载权限控制。
