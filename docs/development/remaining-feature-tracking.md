# 剩余功能跟踪

以已确认 PRD `66-ai-executable-delivery-plan.md` 的 B0–B8 共 127 个任务包为总范围。以下是批次级交接，不是 127 包逐项验收完成矩阵；在包级追踪补齐前不提供完成百分比。已有业务代码不等于整个批次已验收。

|---|---|---|
| B0 工程 | 工程、认证、租户隔离、权限、审计、API 客户端、真实 MySQL 验证 | 全链路固定 E2E、安全与升级回放 Gate |

## 新增交付的包级定位

- B2 搜索增量：管理后台业务搜索已接入供应商/准入申请/资质证照/合同/项目/人员/车辆设备/安全隐患/质量不符合项/绩效评价/现场出入，按对象权限与租户、组织/项目、负责人或创建人范围过滤；人员敏感字段不参与检索和结果输出。个人方案页面已接入默认、应用、另存、更新、重命名和删除，隔离 MySQL 回归见 [业务搜索验收](business-global-search-review.md)。其余业务对象及真实后端浏览器 E2E 未完成。
- B7 期限与催办增量：退出实体期限、逾期展示、人工及租户显式启用的自动站内催办、供应商范围失败台账已接入；升级链和跨供应商集中监控仍缺，参见 [期限催办验收](exit-deadline-reminder-review.md)、[自动催办验收](exit-auto-reminder-review.md)、[失败台账验收](exit-reminder-failure-ledger-review.md)。
- B7 责任待办增量：个人退出待办已接入授权数据范围、实时有效状态、分页、筛选、期限与逾期展示；跨业务人工任务聚合仍缺，参见 [待办验收](my-exit-tasks-review.md)。
- B7 退出通知增量：责任分派与站内投递同事务，模板失效回滚，旧版本不重复投递；管理端个人收件箱及已读闭环已补齐，并接入人工/逾期自动站内催办。独立任务中心聚合和多渠道升级未完成，参见 [通知验收](exit-assignment-notification-review.md)、[自动催办验收](exit-auto-reminder-review.md)。
- B2-07：**部分实现**。个人与租户共享列方案已接入供应商档案、准入申请、资质证照、合同、项目、人员、车辆设备、质量不符合项、绩效评价、安全隐患、现场出入十一表；各表默认互相独立，个人默认优先。其余业务表推广、真实后端持久化页面 E2E 尚未验收。资源页面模拟接口浏览器检查不等于全渠道 E2E，参见 [供应商准入列方案验收](supplier-onboarding-table-views-review.md)、[资源台账验收](resource-table-views-review.md)、[共享列方案验收](tenant-shared-table-views-review.md)、[质量绩效验收](quality-performance-table-views-review.md)、[安全台账验收](safety-table-views-review.md)。
- B7：仍为**部分实现**，详见 `b7-review-and-gaps.md`。解释快照不是统一判定引擎，查询审计不是业务命中台账，退出本地关闭不是外部访问回收。
- B7-02/B7-03：**部分实现**。企业级拦截与解释已共用公开 evaluator，实际业务 WARN/DENY 门禁命中已独立留痕；未完成局部范围、版本化规则及所有业务入口准确动作上下文，不能将共享接口视为完整规则引擎。见 [命中台账验收](restriction-business-gate-hit-review.md)。
- B7-03 动作路由：项目创建/开工/复工、合同创建/生效、资源登记/启用/使用、现场签到已使用准确动作；完整范围上下文、其余渠道及统一 Gate 仍待推进。
- B7 退出处置：八类本地业务实体快照、分页、双版本责任分派、处理说明、实时核验结清及历史保留已接入；不是任务中心联动、局部/强制退出或真实外部访问回收。验收见 [逐实体退出处置](exit-entity-disposition-review.md)。
- B7 外部访问：本地关闭同事务建立门户账号、门禁和接口凭证核查目录；带证据的人工发现、逐外部标识登记/纠错作废、有效账号责任/期限分派均有版本和留痕，分派同步投递站内通知，责任人可查实时待办并定位申请，人工及独立开关的逾期自动站内催办限频且失败回滚，投递失败/恢复状态可见。人工登记/作废不等于真实身份绑定/权限回收；尚无统一跨业务任务中心、连接器/回执，结果继续 `NOT_VERIFIED`，见 [核查目录验收](exit-access-recovery-inventory-review.md)。
- B7 跨供应商监控：按独立权限与供应商实时数据范围筛选未结事项、未分派和逾期；不等于统一跨业务人工任务或外部回收，见 [监控验收](exit-monitor-review.md)。
