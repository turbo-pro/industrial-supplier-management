# 安全台账列方案验收

B2-07 增量：`safety.issue` 安全隐患与 `safety.attendance` 现场出入复用既有个人及租户共享列方案，使用同一租户/持有人/表键隔离、版本并发和审计机制；无新迁移，未改 V25。后端分别要求 `safety:issue:view` 与 `safety:attendance:view`；拥有其中一项权限不能读取另一张表的列目录或方案。

隐患编号与标题、出入人员与现场位置为必显列。页面按方案顺序、显隐、宽度重建台账；整改、验收和签退操作列固定在右侧，任何方案均不能隐藏。方案不影响后台签到资格校验、状态流转、权限或导出。单测覆盖目录、跨业务拒绝和必显列拒绝；复用前期共享方案数据库隔离/并发验收。管理端构建、完整 Maven 回归及 OpenAPI 客户端一致性为本次 Gate。

未覆盖人员凭证、供应商资质等其他台账，也未完成真实后端持久化的浏览器 E2E；B2-07 仍为部分实现。
