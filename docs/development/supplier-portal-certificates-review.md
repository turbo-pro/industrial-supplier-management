# 门户证照查阅与受控原件下载

2026-10-23，B3 门户资质协作增量。范围为“登录 → 本企业已发布证照 → 筛选/分页 → 详情 → 原件下载”，不是门户上传、换证提交或完整准入协作。

## 业务与可见性

- 范围只来自当前门户会话的租户、供应商绑定；客户端租户头、租户/供应商查询参数不能切换企业。必须实时开通 QUALIFICATION 模块，不能因已有门户登录而绕过套餐。
- 内部 DRAFT 和 REJECTED 草稿不发布；展示已核验 VALID 以及 REVOKED、SUPERSEDED 历史证照。类型后来停用不隐藏已有历史证照。
- 到期状态复用内部台账数据库业务日期及预警阈值：到期日当天仍是 EXPIRING，早于当天为 EXPIRED；长期有效/未填到期日的剩余天数为空，不返回特殊大整数。日期、状态及下载都不等同于准入或业务放行证明，实际生效日期仍单独展示。
- 搜索类型名称/编码及证书编号；百分号、下划线与等号按普通字符转义。状态白名单、关键词最多100字、页码0–10000、页大小1–100；稳定次序为更新时间、ID倒序。
- 列表及详情只输出13项证照业务字段；不输出员工/组织/文件ID、内部核验/撤销说明、存储路径或公开文件链接。外企业、跨租户、内部草稿及不存在的ID统一404。

## 下载边界与事务

门户只能通过证照ID取已授权证照关联的当前有效原件；没有任意文件ID下载入口，也不授予员工文件权限。复用存储模块公开适配接口，资格模块不依赖存储实现或文件表。文件被删除返回404，物理内容缺失/存储不可用返回503，不制造下载成功。

下载在事务内经公共写门禁重验会话、账号、企业/退出及平台状态，再查模块与证照绑定。强制 `application/octet-stream`、附件文件名、`nosniff` 与 `no-store`，不内联执行原件。成功打开原件后写 `PORTAL_QUALIFICATION_DOWNLOAD_OPEN` 审计；审计失败关闭已打开流并回滚，不输出内容。该事件是“授权并打开”，不是客户端完整接收证明，传输中断仍可能已有打开审计。

读列表和详情依赖每次请求的门户认证门禁；请求已授权后发生的并发撤销不保证撤回已在传输的字节。没有新增表或迁移，不修改历史V25及其校验。

## 页面与契约

门户企业档案下按需展开证照区，提供筛选、分页、详情焦点、空态、失败重试、下载忙态及下载提示。失效401清除门户身份；模块403只提示未开通，不误登出。历史证照明确仅供留档，网络下载失败可显式重试。退出/档案刷新卸载时中止未完成请求、释放临时对象URL，不将文件内容或凭据写入浏览器存储。

新增 GET `/portal/qualifications`、`/portal/qualifications/{id}`、`/portal/qualifications/{id}/content`，OpenAPI及生成客户端同步。JSON返回不缓存；没有开放门户写入或员工审批端点。
