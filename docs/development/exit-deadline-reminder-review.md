# 退出处置期限与站内催办

## 可独立验收的行为

V40 给退出实体增加 `due_date` 与 `last_reminded_at`，只改新迁移，不改历史迁移。管理人员通过原 `supplier:exit:assign` 设置/清除期限，须填写变更原因并携带申请和实体两个版本；日期按 Asia/Shanghai 业务日，允许今天至一年内，清空表示取消期限。处置中且业务事实仍未结的事项才可变更；终态、过期版本、当前已结或缺失核验能力拒绝操作。

新增独立权限 `supplier:exit:remind`，不自动授予角色。催办重新检查当前同租户 ACTIVE 责任人和真实未结事实。每个事项滚动 24 小时最多催办一次；持有供应商、申请和实体锁，双版本防并发重复，发送时间明确按 UTC 记录。重新分派或变更期限不清空上次催办时间，不能通过切换责任人或取消期限重置限频。

催办通过 bootstrap 适配供应商通知 SPI 与消息模块；首次初始化租户 `SUPPLIER_EXIT_REMINDER` / IN_APP 模板，不覆盖已有模板或恢复停用模板。默认消息仅引用供应商、申请、事项编号和期限，未设置日期明确显示“未设置”，不复制处理说明或人员敏感数据。模板停用、变量不可渲染、账号失效、内容超长或投递异常时，时间、版本、事件、审计和通知同事务回滚；不伪装外部渠道成功。

逾期定义为 OPEN 事项的 due_date 早于当前中国业务日期，截止当天尚不算逾期。退出详情与我的待办展示期限、逾期标签和上次催办（UTC）。历史结清实体保留期限/催办事实但不标记为待处置逾期；个人待办只展示当前有效事项。延期、逾期、催办和已读均不能完成业务或放行批准。

页面新增期限编辑、清空期限及原因留痕、版本冲突保留编辑器、催办确认和冷却期错误提示；无责任人时禁用催办。管理端 Element Plus 统一为中文，保留后续国际化扩展。权限仍由后端独立校验，按钮出现不代表拥有权限。

## 尚未覆盖

这是人工触发站内催办，不是定时自动催办。租户可配置提醒间隔、期限上限、组织时区、自动提醒/升级链、多渠道通知和统一跨业务人工任务中心仍待接入；当前固定默认规则如上。没有自动升级、超期自动审批或强制移交。此项不表示完整 B7 已完成。
