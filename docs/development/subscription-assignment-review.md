# B1-02/B1-11 Console订阅分配与确认

任务卡：2026-11-04，承接供应商容量执行后的平台操作缺口，来源PRD19 PLT-P004、PLT-004-AT-002及既有订阅时窗契约。目标：既有租户选择有效套餐已发布版本→模块/额度与未来计划影响预览→确认立即/未来生效→幂等提交→计划/容量刷新；不是全部菜单/流程/资源影响或B1整包验收。

契约：页面需package:view并由package:assign控制写；后端独立检查assign。预览返回当前tenantVersion、数据库UTC与将替换未来计划数。HTTP分配必填tenantVersion及activationMode(IMMEDIATE/SCHEDULED)，锁租户后比较版本，未来起始过期明确拒绝，不能静默立即生效。保留4参Java可信内部调用的旧时窗语义，HTTP不接受缺少确认信息。候选限定ACTIVE父套餐/PUBLISHED版本，提交当前锁定读重验；注销租户禁止新分配。保存重验实际用量，超量仍拒绝。已有计划被替换会保留历史记录，不删除租户正文。

页面修改任何分配字段即废弃旧预览；确认展示固定目标/UTC时间/模块额度变化/未来计划数及当前影响能力边界。未知结果锁定path/key/body并原请求重试，后续403不推翻先前未知事实；明确409需重新预览，不自动覆盖。成功回执表示该分配曾提交，不保证此刻仍生效，必须刷新计划确认。

范围：platform套餐分配/预览、Console独立组件、OpenAPI/生成类型、专项真实HTTP/隔离MySQL/浏览器及CI/文档。无DDL，不修改管理端视觉/打印草稿。回滚：暂停分配写入再回退；已生效/已取消/未来记录不删、不repair或清库。升级要求调用方发送新必填确认字段，不能混用老HTTP写入方绕过版本检查。

验收SA-01选择/预览/立即生效/未来计划替换；SA-02 stale版本竞争/时间边界/失效父版本/注销拒绝；SA-03幂等重放/冲突/权限撤回/审计失败回滚；SA-04真实用量变化提交重验；SA-05页面未知结果/409重新预览/字段变更/只读/失败/空/窄屏；SA-06真实Chrome与最终库，回填结果后判切片验收。

## 实现与Review

复用现有package:view目录（本页本身要求查看订阅/套餐）选择ACTIVE父套餐/PUBLISHED版本，没有新增免目录授权或商业计费入口。预览及分配按租户锁串行，预览附tenantVersion/asOf/replacedFuturePlans；分配重验版本、父套餐和发布状态，重新读取已接入的实时用量。SCHEDULED时间已过、无效结束时间及数据库年份范围拒绝；CANCELLED/CANCELLING不能新分配。数据表结构不变。旧服务4参调用仅为已有可信内部调用兼容，HTTP canonical DTO必填两个确认字段；旧HTTP调用方缺字段400，须随服务更新。

前端分配与取消/提醒操作互斥，分配面板打开时禁用父面板关闭、分页和变更操作。字段改变废弃旧预览/确认；目标已发布模块和额度完整展示，另列当前预览能识别的模块失效、额度降低/超量及未来计划替换数。只表达现有影响能力，不假称完整菜单/流程评估或已批准只读保留；当前超量仍不允许强制覆盖。

未知写结果只内存保留固定path/key/body，后续403仍保持未知，禁取消/改字段/换目标；成功原回执后关闭分配并刷新计划及额度。回执可能随后被其他操作替换，不能以旧回执断言当前仍有效。刷新/退出丢失本地尝试后须先核对订阅历史，不能自动新键再分配。明确409或规则拒绝清除预览，要求重新评估；不自动重提覆盖并发变更。失败摘要role=alert可聚焦。UTC表单不经本地时区隐式转换，未来起始不会悄悄变成立即生效。
