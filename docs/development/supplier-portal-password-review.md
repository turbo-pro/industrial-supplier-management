# 门户自助修改密码

2026-10-22。仅限已登录门户账号修改自己的密码，不包含管理员重置、邮件/短信找回、邮箱验证、密码历史或完整账号生命周期。

## 可验收目标

1. `POST /api/portal/auth/password` 仅接受独立门户 bearer，参数只有 `currentPassword`、`newPassword`，不接受客户端指定租户、供应商或目标账号；响应 `Cache-Control: no-store`。OpenAPI 使用 `portalBearer`，客户端同步生成。
2. 新密码沿用注册强度规则，至少 12 位，含大小写、数字、符号，最多 72 个 UTF-8 字节，不得与当前密码相同。密码对象的字符串表示脱敏，不写入审计内容。
3. 写事务重新按平台租户→供应商→账号→当前会话锁序核验授权及有效性；不能仅依赖请求过滤器较早的认证结果。停用、退出中、租户/套餐无效、会话撤销或版本过期均不能改密。
4. 原密码错误使用已有登录失败计数：连续 5 次锁定密码操作和新登录 15 分钟；失败计数独立提交。锁定不等于撤销已登录会话，不改变已有会话验证语义。弱密码、同密码不会增加错误计数。
5. 密码哈希、管理版本与令牌版本提升、全部旧会话撤销、`PORTAL_PASSWORD_CHANGE` 审计同事务。审计仅记录账号、操作者和撤销会话记录数量，不含密码、哈希或明文凭证。失败全部回滚；成功不发新令牌，必须重新登录。无迁移变更。
6. 门户登录态按需展开表单，明确影响所有设备；原密码/新密码/确认有标签、密码管理器 autocomplete 和显示/隐藏按钮。阻止不一致、原样复用与明显弱密码；提交期间防重复，服务器响应后清空密码字段。
7. 成功清除本页身份及内存令牌，提示新密码重登。网络结果未知时也清除本页身份，提示先用新密码核查，禁止自动重放改密。不会向浏览器持久存储写入密码或令牌。

UI/UX 技能用于沿用现有门户表单样式、44px 交互目标、可见规则与结果反馈，没有重做管理端或引入新组件库。服务端是最终校验方。
