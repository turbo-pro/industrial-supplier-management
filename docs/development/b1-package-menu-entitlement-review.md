# B1 套餐菜单约束

## 规则与交付

- 授权目录的 `menuCodes` 和 `menus`、角色菜单整体保存、当前用户导航共用同一数据库判定：业务菜单的模块必须存在于当前租户分配的已发布套餐版本，且套餐模块启用、模块目录有效。
- `SYSTEM`、`COMMON`、`MESSAGE`、`WORKFLOW` 是当前固定公共能力，不要求业务套餐模块。未识别、未开通、停用或仅草稿套餐中的业务模块不进入可选目录及导航。
- V63 仅将文件、任务、打印、搜索及其资源中心父菜单从 `RESOURCE` 改为 `COMMON`；人员车辆设备继续属于业务 `RESOURCE` 模块。原迁移及用户角色授权记录不改写。
- 套餐降级后保留原角色授权，便于追溯和恢复；已有登录会话下一次导航请求即按当前套餐过滤。保存未开通菜单返回 `IAM_ACCESS_INVALID_GRANT` / 422，版本、权限、菜单及数据范围在同一事务回滚。
- 现有角色配置页直接使用过滤后的目录，无需修改前端字段或接口结构。已有失效菜单仍可从授权详情读取，提交时需移除失效项。
