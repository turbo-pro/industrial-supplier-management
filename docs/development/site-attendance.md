# 人员现场出入

后台 `/safety/attendance` 管理现场签到、签退与出入记录。接口为 `GET /api/safety/attendance`、`POST /api/safety/attendance/check-in` 和 `POST /api/safety/attendance/{id}/check-out`。

## 可验收规则

1. 只有绑定进行中项目、状态为 `ACTIVE` 且处于当前操作员数据权限范围的人员可以签到。
2. 每次签到均由后端按当天日期重新检查：培训已审核、考试通过、在有效期内；特种作业人员还要有匹配类型的有效凭证。前端展示或历史状态不能替代此检查。
3. 一个人同一时刻最多一条未签退记录；由数据库唯一约束保证并发请求不会重复签到。签退使用版本号，重复或过期版本不能覆盖记录。签退不要求凭证仍有效，以便过期人员正常离场。
4. 列表按租户与数据权限过滤，可按人员和在场状态筛选；历史记录保留，不因人员后来转项目而改写。
5. 本模块是管理后台登记，不代表已接入实体门禁、定位设备或工时结算；这些设备接入时必须使用服务端签到资格规则，不能直接写入数据库。
