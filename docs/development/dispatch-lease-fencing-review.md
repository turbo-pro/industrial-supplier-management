# B0-07 / B2-06 任务与 Outbox 租约保护

日期：2026-10-28。挂靠 B0-07、B2-06 和 GAP-15；依据原 PRD 40 的 `B0-OUTBOX-AT-001`、任务中心现有租约与接管约定。仅交付下列增量，不标记整个 B0/B1 或性能发布 Gate 完成。

## 任务卡与验收边界

- 范围：`ism-operation` 调度服务/Mapper、`ism-resource/print` 执行器、对应单测与隔离 MySQL 集成测试。没有前端或 HTTP 契约变化，没有新迁移，不改旧库。
- 前置：现有 V3 任务与 Outbox 表、任务中心和打印任务均已存在。发现进度、文件绑定、失败回写缺少租约时间检查；仅以配置节点名识别执行，无法隔离同名节点的下一次领取。
- `LEASE-AT-001`：过期执行的进度、文件、失败、完成和续约全部拒绝，数据库记录不变。
- `LEASE-AT-002`：同名节点重新领取生成新的独立所有权标识，旧标识不能回写，新标识正常完成。
- `LEASE-AT-003`：Outbox 过期及接管后的旧确认均拒绝，陈旧重试计数不能决定终态。
- `LEASE-AT-004`：两个并发节点真实竞争一个任务及事件，各只有一个领取成功。
- `LEASE-AT-005`：无效节点名、租期或重试策略在更新前拒绝；领取结果是 RUNNING/PROCESSING 的最新快照。
- `LEASE-AT-006`：打印器在阶段租约检查失败后停止，不能继续渲染、保存或发布结果；既有真实打印 PDF、任务可读和 Outbox 接管回归通过。

## 实现

每次领取将 `节点名:随机 UUID` 写入已有 `lease_owner`，事务内返回领取后的快照。节点名最长 63 字符，完整标识不超过字段 100 字符；租期允许 1 毫秒至 24 小时。内部执行器必须使用返回的 `leaseOwner`，不能再使用配置节点名确认完成。所有回写同时检查状态、所有权与严格未过期租约；相等时间归过期。Outbox 失败还检查读取时的 retry_count，避免陈旧参数错误结束重试。

打印器在读模板、开始渲染及保存前检查阶段写入是否成功，失败即停止；最终关联和完成仍各自验证租约。耗时渲染中不能强行中断，租约丢失后的生成文件不能作为任务成功结果发布。文件写入和任务关联之间仍有孤立文件清理需求，不宣称外部副作用 exactly-once。

## 部署和回滚

本增量改变内部调度调用约定，升级需停止旧工作节点再启用新版本，禁止混用旧版按配置节点名回写的执行器；业务 HTTP 服务和持久化表无需迁移。回滚同样先停止工作节点，等待在途租约结束后回退程序。新旧 lease_owner 均适用原字段，无需 repair、清理任务或修改 Flyway 历史。
