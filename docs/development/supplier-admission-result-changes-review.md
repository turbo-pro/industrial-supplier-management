# 准入公开说明追加更正与撤销发布

2026-10-28，B3 结果发布增量。对外说明允许追加更正或撤销发布，原准入决定、审核版本及原始发布快照均不改写。撤销发布不等于撤销准入，不自动恢复旧发布。

## 可独立验收

1. 员工准入详情在已发布记录下提供更正、撤销和历史入口。历史需准入查看权限及申请数据范围；更正/撤销还需审核权限。门户账号不能进入员工历史或调整接口。
2. 每条发布独立维护publicationVersion，初始0；它与准入申请version不同。更正提交当前发布版本、新对外说明（1至1000字）和供应商可见原因（1至500字）；撤销仅提交发布版本和供应商可见原因。
3. 原公开说明、原发布时间、来源审核和准入结果不变。更正追加CORRECT事件；撤销追加WITHDRAW事件；每次实际成功只递增一次发布游标。更正不会把通过变为拒绝或改采购类别，调整历史发布不改后续审核结论。
4. 同一原发布版本及规范化后的同操作/说明/原因可原样重放，返回当前有效视图，不重复写事件或审计。相同版本改内容或换操作返回409。即使后续已撤销，旧更正/原发布的合法重试也只返回当前撤销状态，不恢复旧说明。
5. WITHDRAW为发布终态，不允许恢复或再次更正；其本身的同请求重试安全。更正与撤销争抢同一版本只能有一个提交，另一方必须刷新；不会同时生效两种操作。
6. 企业→申请→发布记录锁及版本条件更新串行化竞争；事件、游标和ADMISSION_RESULT_CORRECT/WITHDRAW审计同事务。审计失败时游标、有效文本和事件历史全部回滚。
7. 门户响应中的publicComment始终是当前有效说明。更正后不返回旧文本；撤销后仅返回固定撤销提示、明确原因及时间，不返回原说明、更正前说明、旧原因或员工历史。保留申请单号/类别/原结果，但前端标题按WITHDRAWN显示“已撤销发布”，明确不改变原准入决定。
8. 员工历史单独分页保留originalComment及全部追加事件（按change_no降序），可核对每次当时文本、原因及UTC时间；服务端再次复核申请范围和发布归属，不接受跨申请或跨租户引用。
9. 两端当前视图补充publicationState、publicationVersion、adjustmentReason、adjustedAt；原发布重放按数据库原说明比对，不能拿当前已更正/遮蔽文本替代幂等依据。所有发布时间、调整时间按UTC输出Z，页面显示北京时间。
10. 页面先填写明确公开内容再确认。编辑面板打开时固定基准发布版本，刷新不能悄悄使用新版本覆盖旧草稿。结果未知时锁定原请求，允许刷新核查或原样重试，成功提示以实际返回的当前状态为准。门户刷新失败会清除旧结果，避免把失效缓存继续当成最新读取；已在外部留存的内容不属于本接口控制范围。
