# B1-10 平台 Console 品牌配置

2026-11-05任务卡，来源PRD19/33及用户确认的平台/租户Logo配置。平台名称、Logo、站点图标和页脚在Console登录页和工作区公开展示；独立控制面权限修改、版本并发、幂等和审计；租户品牌保持原值，不能通过租户API改平台配置。

PB-01匿名只读白名单公开字段、Console配置查看/管理分权与跨Realm拒绝；PB-02完整保存、CAS、精确幂等/冲突与审计回滚；PB-03安全URL、长度、无HTML执行、图片失败文字回退；PB-04V92升级保留租户配置/业务/V25；PB-05UI未知/403重试、只读/读失败、窄屏键盘；PB-06真实Console保存/刷新/退出仍展示品牌且租户品牌未变，最终库/审计。公开读取不含版本、权限或租户资料；URL需指向公开静态图片，本轮不新建公开上传或签名下载服务，不宣称外部图片站点可达。

范围platform自有表/服务、IAM安全公开路由、V93权限种子、Console独立品牌组件/编辑器、契约/客户端与验证。回滚停品牌写后回退应用，保留新表/审计；无破坏性数据回滚，不修改旧迁移或repair V25。原管理端视觉/打印/规划草稿不纳入提交。B1-10完整公告/品牌资源管理和发布门禁另行核对。


## 实现与契约

- `GET /api/console/branding`：匿名只读四字段，客户端不发送 Bearer；返回系统名、Logo、favicon、页脚，不返回配置版本、权限或租户数据。登录页、工作区、浏览器标题和图标消费这份公开配置。公开读取失败保留默认或最近确认值；异步响应按读取代次丢弃过期结果。
- `GET/PUT /api/console/settings/branding`：分别要求 `platform:branding:view/manage`，后端 Console Realm 校验，租户 JWT 不可用。完整保存携带 `version` 和 `Idempotency-Key`；24 小时按操作者隔离的相同请求回执重放，不同内容或旧版本返回409。
- 新建全局表 `plt_branding`，V93只给平台管理员种子角色授予两个权限；不读写租户 `cfg_tenant_setting`。版本和审计同事务提交，审计失败整体回滚。公开图片不由服务端抓取。
- 页面区分只读、读取失败、版本冲突、确定失败、未知结果；未知结果禁止改表单/关闭/新请求，权限撤回仍保留原请求重试。成功回执与后续读取失败分开提示，重新读取后再允许修改。默认值按钮只填表单，须保存才生效。文字插值无 HTML，图片失败显示 ISM 标识；页脚在正常文档流中。
