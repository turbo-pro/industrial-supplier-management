# 打印模板与打印任务

打印模板按租户和业务类型管理，草稿可编辑，发布后生成不可变版本；打印任务始终引用已发布版本，确保历史单据可重现。模板使用受限 `{{variable}}`，变量声明必须与模板完全一致，渲染值进行 HTML 转义，并拒绝脚本、事件属性和 `javascript:` 内容。

页面配置支持 A4、A5、Letter 和横竖方向。预览使用草稿，正式打印只使用最新发布版本，并提交 `PRINT_DOCUMENT` 异步任务；专用 Worker 只领取该类型任务，依次执行模板读取、PDF 渲染、文件保存和结果回写。任务进度和结果文件复用统一任务中心与文件中心，生成的 PDF 按租户保存并可从任务中心下载。

PDF 由 OpenHTMLToPDF/PDFBox 适配器生成，统一添加模板名称页眉及“第 N 页 / 共 M 页”页脚。外部网络和本地文件资源一律禁止，仅允许模板内嵌 `data:` 资源，防止服务端请求伪造和越权文件读取。部署环境必须通过 `ISM_PRINT_FONT_PATH` 指定一个 PDFBox 可加载、覆盖中文字符的标准 TrueType 字体文件；不接受字体集合路径，字体不可用时任务明确失败，不能生成乱码结果。Worker 可通过 `ISM_PRINT_WORKER_ENABLED` 开关，租约、轮询间隔和节点标识分别由 `ISM_PRINT_LEASE_DURATION`、`ISM_PRINT_POLL_INTERVAL`、`ISM_PRINT_NODE_ID` 配置。

PDF 改动必须生成多页中文样例，再用 Poppler 渲染为 PNG 检查页眉、页脚、页码、表格跨页、字体、边距和截断；未通过版式检查不得标记任务成功。

验收要求：并发旧版本更新/发布冲突；未发布模板不能打印；历史版本不可修改；缺失变量被拒绝；变量值不能注入 HTML；打印任务记录模板版本和业务对象；Worker 不领取其他任务类型；外部资源不能访问；渲染异常进入失败状态并保留错误摘要；成功任务进度为 100，关联 `application/pdf` 结果文件并可从任务中心下载。
