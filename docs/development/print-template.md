# 打印模板与打印任务

打印模板按租户和业务类型管理，草稿可编辑，发布后生成不可变版本；打印任务始终引用已发布版本，确保历史单据可重现。模板使用受限 `{{variable}}`，变量声明必须与模板完全一致，渲染值进行 HTML 转义，并拒绝脚本、事件属性和 `javascript:` 内容。

页面配置支持 A4、A5、Letter 和横竖方向。预览使用草稿，正式打印只使用最新发布版本，并提交 `PRINT_DOCUMENT` 异步任务；任务进度和结果文件复用统一任务中心与文件中心。PDF 渲染器必须实现独立适配器，生成后用 Poppler 渲染页面进行视觉验收，未通过版式检查不得标记任务成功。

验收要求：并发旧版本更新/发布冲突；未发布模板不能打印；历史版本不可修改；缺失变量被拒绝；变量值不能注入 HTML；打印任务记录模板版本和业务对象；最终 PDF 关联结果文件并可从任务中心下载。
