# 门户证照审核反馈

2026-10-26，B3 门户协作增量。在已实现新增、换证与员工核验的基础上，补齐供应商理解结果所需的明确审核说明。

## 可独立验收的规则

- 核验内部意见继续必填且仅供员工查看；新增独立对外说明，不默认复制、不回填历史内部内容。门户拒绝必须填写非空对外说明，批准可不填，最多1000字。内部来源证照不允许发布对外说明。
- 沿用 `supplier:qualification:verify`、资格数据范围和旧版本校验；换证批准同时复核新旧组织范围。拒绝仍可在企业待退出/原证变化时处置，不改变既有批准门禁。
- 决定、说明、发布时间、换证替代/槽位和审计同事务。任何审计或版本失败整笔回滚；只有首次从DRAFT核验成功才能发布，不提供已发布内容改写接口。新增 `PORTAL_CERTIFICATE_REVIEW_PUBLISH` 审计不复制正文，记录决定与是否附说明。
- 门户申请历史只读取绑定企业的明确对外字段；不返回内部意见、员工身份或通用文件ID。审核时间用数据库 `UTC_TIMESTAMP(3)` 保存，接口显式返回Z后缀，门户按标明的北京时间（Asia/Shanghai）显示，避免裸时间少8小时；后续撤销/替代不改写原核验说明。
- 历史结果未发布说明时明确提示联系邀请方；本次批准未附说明则显示“本次审核未附说明”。说明按纯文本展示，保留换行并允许长词换行。
- 管理端核验弹窗分开标注内部/对外两项；拒绝时对外必填，说明公开范围及不可改写。失败保留输入、显示可聚焦错误，提交中禁用重复提交和取消。详情可回看已发布说明。

## 页面、数据库、接口

V78仅给 `qua_portal_submission` 添加可空 `public_review_comment`、`public_reviewed_at`，历史行不自动回填。旧迁移及旧库校验策略不变，无新部署组件。

现有 POST `/qualifications/{id}/verify` 增加可选 `publicComment`（门户拒绝条件必填）；员工详情增加 `portalSubmission`、`publicReviewComment`。门户申请列表/幂等提交结果增加 `publicReviewComment`、`reviewedAt`。OpenAPI和生成客户端同步，未新增越权的独立发布入口。旧客户端仍可核验内部证照或批准门户证照；门户拒绝调用必须升级为显式提供 `publicComment`，缺失时返回400，不能静默把内部意见公开。管理端已有未提交视觉改动继续保留，仅选择性提交核验入口、说明展示及新增独立弹窗；构建和浏览器验收基于当前工作区执行。
