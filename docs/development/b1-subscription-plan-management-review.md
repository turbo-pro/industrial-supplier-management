# B1 订阅计划查询与取消

## 业务与接口

新增 Console 订阅分页接口：返回套餐/版本名称、当前有效版本、租户版本和 UTC 读取时刻，并区分 SCHEDULED、EFFECTIVE、EXPIRED、SUPERSEDED、CANCELLED、UNAVAILABLE。底层 ACTIVE 只是候选记录，不再让调用方直接将它解释为“当前生效”。旧指针尚无订阅历史时可以显示当前版本，但不会捏造历史记录。

新增未来计划取消接口，须提交读取列表时的 `tenantVersion` 及非空原因。服务端在租户行锁下检查所属租户、版本和数据库时间；只允许取消尚未生效且仍为 ACTIVE 的记录。取消时间、操作人及原因由 V67 新字段保存，不删除历史，不改当前订阅窗口，也不直接更改最近分配指针。实际权限仍由有效版本解析获得。

查看需要 `platform:package:view`，取消需要 `platform:package:assign`。取消与版本递增、审计同事务；接口沿用平台幂等机制，同一用户/操作/键和请求重放返回原结果，不重复取消或审计。已生效、已替换、已取消或陈旧版本返回 409；路径租户与计划所属租户不符返回 404。列表 `canCancel` 是读取时提示，写入 SQL 仍按数据库当前时间检查边界。

## 验收

隔离 MySQL / MockMvc 使用真实 Console 登录与授权，覆盖支持人员可读不可取消、分页/大小校验、跨租户计划 ID 拒绝、陈旧版本拒绝、生效记录拒绝、成功取消与幂等重放、审计仅一条、取消后元数据读回和当前模块保持有效。原时窗、套餐、IAM 与 V25 升级一并回归。最终执行结果见推进记录。

OpenAPI、生成客户端同步。Console 租户表新增“查看订阅计划”，独立面板提供分页、状态、UTC 时间、取消元数据、只读提示及取消确认表单。必须填写原因，冲突后刷新，网络重试复用相同请求幂等键，加载/提交时禁用重复操作。沿用现有 Console 样式；截图检查发现旧表格继承登录浅色文字，增加控制台表格文字继承修复。未修改已有 admin 界面改动。

2026-10-18 最终后端结果：B0InfrastructureIT 23/23、PerformanceMigrationUpgradeIT 1/1，失败/错误/跳过均为 0；客户端生成、类型检查和 Console 构建通过。Console 原有 Playwright 回归 4/4 通过；默认缓存 Chromium 缺失时失败，改用本机 Chrome channel 后通过，未安装或改系统浏览器。当前 Node/pnpm 低于仓库要求，构建有版本警告但退出为 0。

新面板通过 Playwright CLI + 模拟接口验证管理员打开/填写原因/确认取消/取消后记录及当前版本不变、支持人员查看仍待生效记录但无取消按钮；桌面及 390px 面板截图已检查。浏览器仅出现 favicon 404，没有新增业务脚本异常。此验证不是与真实后端联调。截图保存在本地忽略目录 `output/playwright/subscription-cancelled-readable.png` 与 `subscription-readonly-panel.png`，不是公开 Demo 或发布截图。
