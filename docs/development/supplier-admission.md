# 供应商准入

供应商准入将候选供应商从“已建档”推进到“审核通过并可开展业务”。默认使用内置状态机，租户未配置工作流也可使用；数据表保留 `workflow_instance_id`，启用自定义审批后可关联 Flowable 实例。

## 状态与规则

- `DRAFT -> SUBMITTED`：申请人提交，所有必填资料必须已上传并关联文件。
- `SUBMITTED -> APPROVED`：审核通过；若供应商仍为草稿，同事务转为有效。
- `SUBMITTED -> REVISION_REQUIRED`：退回补正；申请人可编辑资料并再次提交。
- `SUBMITTED -> REJECTED`：审核拒绝，终态；需重新发起新申请。
- 资料类型在单据内唯一，“已提供”必须有文件 ID，防止仅勾选而未上传。
- 所有编辑、提交和审核均使用 `version` 乐观锁，全部动作写入审核轨迹和全局审计日志。
- 数据访问按申请归属组织应用 `supplier:admission` 数据权限；越权详情按不存在处理。
- 租户已有有效采购品类时，新申请必须选择该供应商已关联的有效品类；服务端按品类 ID 校验并保存 ID 与当时名称快照，不信任客户端传入名称。提交和批准会再次校验品类仍有效且仍关联该供应商。目录停用、关联移除时不允许借旧草稿完成准入。旧申请无品类 ID 的自由文本仍可查看、补正与流转；已绑定目录的申请不能退回自由文本。租户尚未启用品类目录时，新申请仍沿用自由文本。

## 管理端补正与查看

- 台账“详情”展示申请字段、材料提供状态及审核轨迹；全局搜索按申请 ID 直达详情，不依赖当前列表分页。
- 草稿和待补正申请可在管理端编辑采购类别、准入原因、预计采购额与材料；已有必填材料不可从页面删除。保存时提交当前版本，成功后刷新台账与详情。
- 保存成功后新增 `UPDATE` 审核轨迹与 `ADMISSION_UPDATE` 全局审计；版本冲突或不允许编辑的状态不写入材料和轨迹。材料表单可直接分片上传并回填文件 ID，支持重选同一文件续传；详情可按文件中心权限下载材料，受限图片可预览，PDF 等类型暂只下载。
- 创建、补正、提交和批准时检查所关联文件仍属于当前租户且可用；不能以其他租户、已失效或不存在的文件 ID 通过服务端校验。

## 权限点

- `supplier:admission:view`
- `supplier:admission:apply`
- `supplier:admission:review`

## 可独立验收

1. 草稿缺少任一必填资料时不能提交。
2. 资料标记“已提供”但没有文件 ID 时保存失败。
3. 审核人可通过、退回补正或拒绝，且必须填写审核意见。
4. 补正申请可修改并再次提交，历史审核轨迹完整保留。
5. 准入通过后，草稿供应商自动变为有效；已经有效或停用的供应商状态不被覆盖。
6. 旧版本提交或审核返回 409；终态申请不能再次审核。
7. 不同租户或组织数据范围之间不能读取或操作对方申请。
8. 从全局搜索打开非当前分页的申请详情，能查看材料和审核轨迹；待补正资料保存后版本递增，轨迹与审计各增加一条；旧版本补正不能覆盖新资料。
9. 新申请不能提交未绑定或停用的目录品类；提交/批准前停用或移除关联，状态不推进；旧单据仍展示原文本，不因目录上线丢失历史。
