# B1-01、B1-06、B1-07、B1-12 支持会话交付切片

依据 PRD 68 和 GAP-01。现有支持授权接口只计算租户批准范围与当前权限的交集，返回的就绪状态供 Console 查看。下一切片将会话签发、兑换、校验、撤销和业务读取作为一个上线单元，避免会话入口早于审计或撤销能力开放。

- Console 会话创建仅允许符合当前资格的原申请人操作。创建时在事务内复核平台审批、租户授权、有效期及当前交集。会话冻结创建时的范围上限，之后每次访问仍与当前授权求交。
- 一次性进入凭证短时有效并绑定浏览器，服务端存摘要。兑换时原子消费，竞态仅允许一次成功。支持凭证使用独立身份类型，携带操作者、目标租户和支持会话标识。
- 首个可验收业务面仅覆盖现有 SUPPLIER_BASIC_READ_V1 档案白名单投影，沿用租户及组织范围。受控入口与普通员工凭证区分，固定横幅展示真实操作者、租户、剩余时间及批准范围，退出触发终止。
- 真实读取和拒绝写入审计。撤销后复用同一凭证重试须立即失败。浏览器验证双身份、字段裁剪、撤销、横幅和退出，隔离库验证兑换竞争、过期、跨浏览器与跨租户拒绝及审计持久化。

修改范围涉及新迁移、平台会话存储、IAM 支持凭证校验、受控供应商投影、Console 和管理端入口、OpenAPI 与生成客户端。回滚先关闭入口并终止活动会话，再回退应用，保留审计和已消费凭证记录。此文件登记实施契约，当前实现状态仍见租户支持授权专项。

2026-11-06 完成待启用记录切片。V94 增加会话存储。平台原申请人在有效双审批和非空授权交集下，可通过内部服务创建 PENDING 记录。记录关联具体租户授权决定，冻结有效角色、组织与字段范围，期限以租户授权截止为界。创建审计随记录同事务写入。V94 可以保留在库中，应用回滚后停用内部创建能力。

2026-11-06 凭证兑换切片对应 SUPPORT-AT-003。V95 增加进入凭证摘要、浏览器绑定摘要、截止和激活时间。原申请人使用 Console 身份为待启用会话签发凭证，调用方需提供由浏览器产生并保管的 256 位随机秘密。进入凭证有效期最长 60 秒，受租户批准期限约束。兑换重新检查当前资格、原批准决定和冻结范围交集，再由条件更新原子消费凭证。激活与审计同事务，成功后清除凭证摘要。应用回滚可保留 V95 列，已签发短时凭证自然到期。此切片为内部服务，支持身份令牌、每次业务访问复核、主动撤销入口和横幅将在后续闭环接入。
