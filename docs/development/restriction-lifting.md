# 独立解除审批

企业级限制通过独立申请解除，不覆盖原批准记录。申请必须携带租户内有效文件、理由，由非申请人审批；批准时再次核验质量不符合项、安全隐患及绩效整改，缺失核验模块时拒绝放行。

观察名单默认须完成七天观察期，起点为原批准时间。租户可在“系统管理 → 租户配置”设置 `restriction.watchPeriodDays`（1–3650 整数天，默认 7）。服务配置 `ism.restriction.lift.watch-period` 为部署级下限（默认 `P7D`，不允许负值）。

提交解除申请时记录 `observationSeconds` 快照；批准与核验取租户当前配置、部署下限、待审申请快照的最大值。因此待审期间下调配置不缩短原申请观察期，上调则立即纳入批准核验。配置按租户当前读并参与事务，不使用可能过期的缓存。V34 为旧观察解除申请保守回填七天；非观察申请为零。部署下限仍参与旧申请核验。

长期黑名单、限期限制仍须完成整改，但不自动附加观察期。本页只接入风险观察策略，不代表其他已有配置存储项均已接入消费逻辑。配置需 `system:setting:view/manage` 权限，写入使用幂等键和版本号；首次写入竞争返回冲突而非数据库错误。

每条限制最多一个待处理申请、一条解除结果。驳回可重新申请；已解除不可再次申请。乐观版本校验和供应商行锁保护审批。批准只使该条限制失效，同供应商其他有效限制继续阻断业务。历史申诉不会自动产生解除。

管理后台入口：风险观察与限制 → 解除审批。支持核验、证据登记、分页记录及批准/驳回。权限分别为 `supplier:lift:view/create/review`，迁移不自动向所有角色授权。旧直接撤销接口停止处理，返回验证失败。

当前范围为企业级限制；局部工厂/组织限制、人员设备限制、门户自助仍未完成，不能宣称完整 B7 已交付。

验收：自审拒绝、缺失核验拒绝、观察期未结束拒绝、失效证据拒绝、旧版本不生成结果、原批准记录保持、只解除一条而其他限制继续有效。
