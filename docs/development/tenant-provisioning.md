# 租户开通与生命周期

Console 创建租户时只写入控制面记录和已发布套餐订阅，状态为 `PROVISIONING/PENDING`。初始化接口在单个事务内创建租户身份域、总部组织和首管理员；成功后切换为 `ACTIVE/READY`。首管理员密码只接受写入、不回显、不进入审计摘要，并强制首次登录修改。

租户生命周期为 `PROVISIONING -> ACTIVE -> SUSPENDED -> ACTIVE`，注销只能从 `SUSPENDED` 进入不可逆的 `CANCELLED`。暂停和注销同步禁用租户身份域、递增全部用户令牌版本，现存会话立即失效；恢复不会还原已注销租户。

Console 只能读取租户编码、名称、状态、区域设置、套餐等控制面摘要，不能借此访问租户业务正文。所有写接口必须携带 `Idempotency-Key`，创建、初始化和生命周期变化写入平台审计。

验收要求：重复租户编码被拒绝；未发布套餐不能分配；初始化失败不留下半成品身份数据；初始化后生成唯一总部和首管理员；首次登录必须改密；暂停后无法登录；恢复后可登录；注销前必须暂停且注销不可逆。
