# 供应商资质与证照

资质证照模块维护租户自己的资质类型、供应商证书、核验结论、有效期预警、撤销和换证链路。证照文件复用统一文件中心，不重复保存二进制文件。

## 核心规则

- 资质类型由租户配置：编码、名称、分类、是否必须有有效期、默认预警天数和启停状态。
- 证照新建后为 `DRAFT`，核验通过变为 `VALID`，核验拒绝变为 `REJECTED`。
- 有效证照按查询日期动态显示 `EXPIRING` 或 `EXPIRED`，无需依赖定时任务刷新状态；预警天数可按证照覆盖类型默认值。
- 长期有效证照不能填写到期日；要求有效期的类型必须填写到期日；生效日不得晚于到期日。
- 只有 `VALID` 证照可以撤销或换证。换证创建关联旧证照的新草稿，并将旧证照变为 `SUPERSEDED`，形成可追溯链路。
- 供应商、资质类型和证照文件创建后不可换绑；所有写操作使用 `version` 乐观锁。
- 数据按供应商归属组织执行 `supplier:qualification` 范围控制，越权详情按不存在处理。

## 可独立验收

1. 租户可配置资质类型；编码重复返回 409，编码创建后不可修改。
2. 要求有效期的资质缺少到期日不能保存，长期有效与到期日不能同时填写。
3. 草稿可以核验通过或拒绝；非草稿不能重复核验。
4. 距到期日小于等于预警天数显示“即将到期”，日期已过显示“已过期”。
5. 有效证照可以撤销且必须填写原因；撤销后不可恢复。
6. 换证后新证照为草稿、旧证照为已被替代，并保留父子关联。
7. 不同租户和组织范围之间不能读取或操作对方证照。
