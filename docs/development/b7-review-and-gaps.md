# B7 集中 Review 与后续验收缺口

本轮以 PRD `58-b7-restriction-exit-acceptance.md` 为验收依据。当前实现不是完整 B7，不应对外标记“全部验收通过”。

## 已覆盖的本地入口

| 入口 | 企业黑名单/限期限制 | 观察名单 | 处置操作 |
|---|---|---|---|
| 准入创建、提交、批准 | 阻断 | 不阻断 | 驳回/补正仍可处理 |
| 合同新建、激活 | 阻断 | 不阻断 | 结束/终止仍可处理 |
| 项目新建、开工、复工 | 阻断 | 不阻断 | 暂停/取消/结束仍可处理 |
| 人员登记、启用 | 阻断 | 不阻断 | 停用、离场仍可处理 |
| 车辆设备登记、投入使用 | 阻断 | 不阻断 | 维修、退役、交接仍可处理 |
| 现场签到 | 阻断，且复查人员资格 | 不阻断 | 签退仍可处理 |

均通过供应商模块公开接口，不允许页面参数自行决定资格。审批和新增业务使用供应商行锁；当前读复查限制与供应商状态，签到再锁定人员并重新检查数据范围、项目和凭证。

本轮修复：资源和签到遗漏限制判定、合同/项目激活绕过限制、准入批准未复查限制与自审、限制生效并发时的旧快照风险。

## 退出检查覆盖

逐实体责任分派已接入事务性站内通知与管理端个人收件箱，见 [通知验收](exit-assignment-notification-review.md)。当前责任人实时退出待办已接入，见 [待办验收](my-exit-tasks-review.md)，由申请/实体当前状态过滤失效事项，不将历史消息等同于实时待办。期限与人工站内催办已接入，见 [期限催办验收](exit-deadline-reminder-review.md)；逾期站内自动催办与租户开关/间隔见 [自动催办验收](exit-auto-reminder-review.md)，供应商范围失败记录见 [台账验收](exit-reminder-failure-ledger-review.md)。租户级一层逾期升级及有效账号搜索选择见 [升级验收](exit-escalation-review.md)。跨供应商当前未结事项集中监控已接入，见 [监控验收](exit-monitor-review.md)；统一跨业务人工待办及组织逐级升级链仍缺。

合同/项目未结束、人员未离场、车辆设备未交接、现场未签退、质量不符合项/安全隐患未关闭、绩效改进未验收、财务未核验均阻止退出。财务默认 ERP 模式未知即阻断；显式人工模式须证据与独立复核。资产退役不等于交接。

这只表示本地业务退出条件通过，不能宣称外部账号或门禁已经回收。

2. 管理后台证据申诉、独立解除申请与结果已实现，解除复核质量、安全、绩效整改和观察名单观察期。租户观察期配置页及待审快照已接入；仍缺门户自助、临时暂停、关联主体识别及局部限制。参见 [解除实现](restriction-lifting.md)。
3. 企业级正常退出/淘汰申请、聚合处置项、独立审批与本地业务关闭结果已实现；八类本地业务逐实体快照、分页、责任分派、说明及重新核验已接入，参见 [逐实体验收](exit-entity-disposition-review.md)。个人待办、期限、人工与逾期站内自动催办及一层租户级升级已补齐；批准时本地记录摘要封存见 [封存验收](exit-local-archive-review.md)。仍缺统一人工任务、组织逐级升级链、合作关系/局部范围、计划生效、完整文件归档、紧急淘汰任务及高风险强制移交。外部访问仍为未核验，参见 [正式退出](supplier-exit-application.md)。
4. 供应商门户身份绑定与账号回收、外部门禁/账号回收任务状态、幂等重试与失败可见。当前尚无供应商门户账号绑定模型或真实回收连接器，不生成虚构成功回执。
5. 对上述全部入口、租户范围、并发、回调幂等、缓存与审计做 B7 Gate 回归，再进入发布验收。

系统内可实现的规则、申请和任务模型继续按此顺序推进；真实 ERP/门禁连接器需要实际厂商协议、测试环境和凭据。未确定的外部协议不能在代码中假定为已集成。现有项目没有 H5、分包和扫码入口的完整验收，因此也不能宣称全渠道限制一致性已完成。

动作接入进展：项目创建、开工/复工、人员资产登记/启用/使用和现场签到已改为准确动作，准入包装已使用 QUALIFICATION_APPLY。合同创建与生效已分别接入 CONTRACT_CREATE 与 CONTRACT_ACTIVATE；组织/工厂/项目范围上下文尚未完整提供，不能开放局部范围规则。详见 [入口接入验收](entry-action-routing-review.md)。
