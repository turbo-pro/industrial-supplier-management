## 可独立验收的范围

- 门户登录后自动读取“本企业档案”，可手动刷新；展示企业名称、编码、简称、统一社会信用代码、类型、行业、国家地区代码、省市、地址、成立日期、网站、档案状态，以及有效的已关联采购品类名称/编码。
- 空字段显示“未填写”，无品类显示明确空态。档案状态 DRAFT 显示“草稿”、ACTIVE 显示“已启用”，不将其解释成准入批准或合同资格。
- 刷新开始清除旧档案；网络失败显示可重试错误并聚焦提示。401 清除门户内存身份并回到登录；退出/改密导致组件卸载时取消请求，阻止迟到响应重新展示数据。网站仅展示文本，Vue 转义业务字段。
- 手机尺寸下详情标签与长内容可换行，刷新按钮有加载反馈及禁用状态，保留现有门户外观和键盘焦点样式。

## API、数据与身份边界

`GET /api/portal/supplier-profile` 需要有效的门户专用 bearer，返回 `Cache-Control: no-store`。没有客户端可选择的 tenantId/supplierId；未知查询参数及 `X-Tenant-Id` 不参与范围计算。OpenAPI 和生成客户端已同步。

IAM 认证过滤器在每次检查当前会话、账号、租户/模块、供应商和待审退出后，安装公共 `PortalIdentityContext`，并保留内部权限 denyAll。上下文必须与 TenantContext 的租户及操作者一致；退出过滤器作用域后清理。供应商模块按该绑定执行独立只读查询，不依赖 IAM 的实现类，不查询 IAM 账号表，也不授予员工角色或内部数据权限。

企业字段使用独立 SQL 投影，只读取白名单字段；不返回联系人/个人资料、法定代表人、内部组织、风险评级、备注、财务字段、账号哈希、令牌或内部审计元数据。采购品类查询同时约束租户和供应商，仅返回已关联且 ACTIVE 的品类。档案查询再次排除停用、删除、已退出及有待审退出申请的主体，无法读取时返回 404。

复用既有 `sup_supplier`、`sup_purchase_category` 和 `sup_supplier_purchase_category`，无需新增表或迁移。门户认证开关继续默认关闭；受控启用认证后即可使用本功能。
