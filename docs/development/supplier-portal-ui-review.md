# 门户注册与认证页面验收

2026-10-21，仅补 Vue 3 独立门户，不修改现有管理端用户改动、数据库迁移或部署开关。通过共享生成 API 客户端消费已有 register/login/me/logout 契约，无新增接口或表。

## 已实现

- 邀请注册、密码确认和复杂度校验；成功后引导使用邀请方提供的租户编码登录，不自动批准准入或自动登录。
- 登录、绑定身份、服务器身份复核、当前会话退出；错误凭证、限流、功能关闭、冲突和网络不确定结果有独立提示。
- 禁止重复提交；退出失败保留重试入口，不把网络失败标记为撤销成功。身份复核 401 清理本地身份并要求登录。
- 令牌仅存内存，不写 URL 或浏览器存储；密码提交后清空。刷新需重新登录，但不代表服务端会话已撤销。注册不传租户或供应商绑定字段，后端独立强制绑定与授权。
- 沿用青色企业配色、中文系统字体、可聚焦错误摘要、标签与辅助描述、44px 控件及移动布局。UI/UX 技能指导这些规则；未采用营销 Hero/CTA 或外部字体建议。
