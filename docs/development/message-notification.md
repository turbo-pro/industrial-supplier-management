# 消息模板与通知中心

消息模板按租户隔离，以稳定模板代码和渠道标识业务用途，支持站内信、邮件、短信、企业微信和钉钉渠道定义。当前开源基线启用 `IN_APP`，其他渠道保留适配边界，未配置时明确拒绝发送。模板使用受限的 `{{variableName}}` 占位符，保存时要求模板变量与声明集合完全一致，发送时要求必填变量齐全，避免静默产生残缺消息。

发送会校验所有收件人属于当前租户且账号有效，为每位收件人生成独立发送记录和站内收件箱记录，并可关联业务类型与业务 ID。用户只能读取和标记自己的消息，支持未读数、单条已读和全部已读；模板管理、消息发送和个人收件箱分别授权。

验收要求：跨租户收件人不可发送；未知或缺失变量被拒绝；内容按变量正确渲染；每个收件人具有独立投递记录；未读数随单条/全部已读准确变化；非站内渠道未配置时不伪造成功结果。
