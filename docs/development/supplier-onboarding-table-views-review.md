# 供应商准入与资质台账列方案验收

## 范围

管理后台的准入申请、资质证照台账接入既有个人/租户共享列方案组件。分别注册 `supplier.admission`、`supplier.qualification` 两个表键；与其他表及彼此的方案、默认值和权限相互独立。申请单号、供应商名称、证书编号为相应表的必显标识列；操作列保持固定，不在可配置目录中。其他列可隐藏、排序和调整宽度。方案只影响页面呈现，不改变列表查询、业务审批、核验或文件访问权限。

后端目录读取同时要求 `table:view:manage` 与该表的业务查看权限；共享方案写入额外要求 `table:view:publish`。前端无方案权限或读取失败时使用系统列。旧方案的版本冲突、跨用户和跨租户隔离沿用通用列方案服务。

## 验收

- `TableViewServiceTest` 覆盖两表的独立业务权限、目录键与必显列校验。
- 隔离 MySQL `B0InfrastructureIT` 覆盖两表个人方案创建、跨用户/租户不可见、他人不可删除及删除回退；通用共享方案的权限、默认优先级和版本规则由原有回归覆盖。
- 管理端类型检查/构建及 API 契约生成一致性通过；未新增迁移。

尚未执行真实后端浏览器持久化 E2E，不将前端构建视作页面交互验收。资质类型配置表不属于本次列方案范围。
