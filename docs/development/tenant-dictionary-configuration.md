# 租户字典与配置中心

字典采用“系统定义 + 租户覆盖/扩展”的两层模型。系统字典类型和基础条目由数据库迁移统一发布，租户不复制系统数据；读取时实时合并系统条目与当前租户条目。租户可覆盖系统条目的显示名称、值、顺序和启停状态，删除覆盖后立即恢复系统默认值。只有标记为 `tenantExtensible` 的类型允许新增租户专属条目，字典类型代码和条目代码作为稳定业务标识，不允许租户重命名。

租户配置采用受控配置定义，不接受任意配置键。当前支持系统名称、Logo、Favicon、页脚、长期未登录改密天数和单文件大小上限；未配置时返回系统默认值。值在服务端按 `STRING/URL/INTEGER` 类型校验，后续对象存储、打印、消息等模块通过新增定义扩展，不修改租户表结构。

所有查询从服务端租户上下文取 `tenant_id`。写操作要求 `Idempotency-Key`、乐观锁版本和独立的字典/配置管理权限，并写入审计日志。Console 只维护系统定义与套餐能力上限，不直接修改租户覆盖值；平台代运维必须通过后续受审计的租户模拟访问入口执行。

验收要求：不同租户读取相同系统默认值但覆盖互不影响；可扩展字典允许租户新增条目；封闭字典拒绝新增但允许覆盖已有条目；删除覆盖后恢复系统默认；未知配置键、非法 URL 或负整数被拒绝；并发旧版本写入返回冲突；租户管理员初始化后自动获得菜单和权限。
