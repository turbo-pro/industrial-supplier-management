# 跨供应商退出处置监控验收

B7 增量：`GET /supplier-exit-tasks/monitor` 提供当前 `SUBMITTED` 申请下 `OPEN` 逐实体处置项的租户内分页监控。V45 新增独立 `supplier:exit:monitor` 权限、管理端菜单及 `(tenant_id,state,due_date,id)` 索引；既有角色不自动获得权限或菜单，租户管理员须在角色配置中显式分配。服务端同时应用 `supplier:master` 实时数据范围，按未分派、逾期、事项类型、供应商编码/名称筛选；关键词通配符转义。空范围拒绝返回业务数据，其他租户不可见。排序优先逾期和未分派，再按期限及 ID，日期沿用现有上海业务日。

页面在“退出处置监控”展示责任人、期限、逾期、说明、最近催办与业务/退出申请入口。监控只读，不含完成、强制移交、审批或访问回收按钮。入口打开原供应商退出申请弹窗；实际结清仍由对应业务处理和重新核验决定。申请撤回、驳回、本地关闭或实体核验结清后不再出现；历史记录保留在原申请详情。

验收：单测覆盖独立权限、组织范围、参数校验和缺省数据范围；隔离 MySQL 集成测试覆盖未分派、分派后过滤、组织/租户隔离、逾期、结清后移出，完整 Maven 回归与前端构建/API 契约一致性通过。未实现跨业务统一人工任务、升级链或外部回收；监控项是当前状态快照，不代表真实外部连接器成功。
