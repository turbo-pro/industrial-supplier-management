# 合同与项目管理

合同与项目是供应商准入后的履约入口。合同绑定一个有效供应商，项目绑定一个供应商并可选关联该供应商的有效合同，后续人员、车辆设备、安全和质量数据统一挂到项目。

## 业务规则

- 合同编号、项目编码均在租户内唯一且创建后不可修改。
- 只有有效供应商可创建合同和项目；项目关联合同时，合同必须有效并属于同一供应商。
- 合同状态：`DRAFT -> ACTIVE -> COMPLETED/EXPIRED/TERMINATED`，草稿也可直接终止；终止必须填写原因。
- 项目状态：`PLANNED -> ACTIVE -> SUSPENDED/COMPLETED/CANCELLED`，暂停后可以恢复；暂停或取消必须填写原因。
- 合同或项目只有草稿/计划状态可修改核心字段，状态变更全部使用乐观锁并记录审计日志。
- 合同支持租户、组织、负责人和创建人范围；项目额外支持指定项目范围。
- 项目启动和完成时自动记录实际开始、结束日期。

## 可独立验收

1. 无效或已退出供应商不能新建合同或项目。
2. 合同和项目的开始日期晚于结束日期时保存失败。
3. 项目不能关联其他供应商的合同，也不能关联非有效合同。
4. 非法状态跳转被拒绝；终止合同、暂停或取消项目缺少原因时被拒绝。
5. 项目启动、完成后分别产生实际开始和结束日期。
6. 旧 `version` 修改或变更状态返回 409。
7. 不同租户、组织、负责人和指定项目范围的数据互不可见。
